# Frost-Siedlung

Ein kleines Aufbau- und Jagdspiel für den Browser (optimiert für das iPad), inspiriert von Werbe-Minispielen im Stil von „Whiteout Survival“.

## Spielprinzip
1. Jage Eisbären und Stachelbären hinter dem Zaun – der Angriff passiert automatisch, sobald du nah genug bist.
2. Das Fleisch stapelt sich auf deinem Rücken. Bring es zur Theke (Kreis mit Fleisch-Symbol).
3. Stell dich an die Kasse (Kreis mit $), damit die Überlebenden kaufen.
4. Sammle das Geld ein und stell dich auf die grauen Bau-Felder, um Ausbauten freizuschalten:
   Wirbelnde Äxte, Kassierer, Rucksack, Jäger, Holzfäller-Hütte, Goldmine mit Lore, Schlitten …
5. Ziel: Baue den **Großen Ofen** und rette die Siedlung. Danach kannst du endlos weiterspielen.

Der gelbe Pfeil und der Hinweis oben zeigen immer, was als Nächstes zu tun ist.

## Steuerung
- **iPad/Handy:** Finger irgendwo auf den Bildschirm legen und ziehen (virtueller Joystick).
- **Computer:** WASD oder Pfeiltasten, Esc = Pause.

Der Spielstand wird automatisch im Browser gespeichert.

## Auf dem iPad spielen
Das ganze Spiel ist eine einzige Datei: `index.html` (keine Installation, keine Internetverbindung nötig).

Am einfachsten über GitHub Pages:
1. Im Repository auf GitHub: **Settings → Pages → Branch** wählen und speichern.
2. Danach auf dem iPad in Safari öffnen: `https://<benutzername>.github.io/Projects/FrostSiedlung/`
3. Tipp: Über **Teilen → Zum Home-Bildschirm** läuft das Spiel wie eine App im Vollbild.
